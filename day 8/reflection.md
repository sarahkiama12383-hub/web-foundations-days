# Course Reflection

Reflecting on this software engineering and system design journey, the most difficult concept for me to grasp initially was managing databases and understanding how asynchronous API requests and multiple users hitting a server simultaneously can cause data collisions. I overcame this challenge by breaking down backend workflows into smaller pieces, studying how operations and Redis locks work, and practicing relational database design step-by-step through our labs.

According to feedback received during project reviews, I plan to improve my focus on writing cleaner, more organized code separation and anticipating edge cases in API error handling. Moving forward, my next steps in learning are to further learn more about backend development with Node.js and explore cloud deployment workflows to take my mobile-built applications into full production environments. This course has built a strong foundation in thinking like a professional software engineer.
